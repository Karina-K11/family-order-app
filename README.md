# 家庭点菜小程序

给家人用的点菜网页：微信里点开就能选菜、写备注、提交订单；主人在另一台手机上打开同一个链接看订单、标记完成。**不涉及付款**，没有账号体系，菜单可以在网页上直接增删改。

## 功能一览

- **点菜页**：按分类浏览菜品，加购/减购份数，每道菜可写备注（如少辣、不要香菜），提交时填写点菜人称呼。
- **订单板（主人）**：按时间倒序展示所有人的订单，含称呼、时间、明细、备注、合计金额；可标记「完成 / 取消 / 删除」，每 10 秒自动刷新。
- **菜单管理（主人）**：新增、编辑、删除菜品，设置价格、分类、描述，上下架。
- **口令保护**：订单板和菜单管理需要输入管理口令；点菜页不需要口令，家人直接用。

## 文件结构

```
family-order-app/
├── server.js          # 后端服务（零依赖，Node 内置模块）
├── package.json
├── Dockerfile         # 可选：容器部署用
├── public/
│   └── index.html     # 前端页面（点菜 / 订单板 / 管理 三合一）
└── data/              # 运行后自动生成：menu.json 菜单、orders.json 订单
```

## 一、在自己电脑上启动

1. 安装 Node.js 16 以上版本（<https://nodejs.org>，一路下一步即可）。
2. 在本目录打开 PowerShell，运行：

   ```powershell
   node server.js
   ```

   看到 `家庭点菜服务已启动：http://localhost:3000` 即成功。
   （也可以用 `npm start`。）

3. 本机浏览器打开 <http://localhost:3000> 即可使用。

### 改管理口令

默认口令是 `8888`，**上线前请改掉**。启动前设置环境变量：

```powershell
# PowerShell（当前窗口有效）
$env:ADMIN_PIN="你自己的口令"; node server.js
```

或在系统环境变量里永久添加 `ADMIN_PIN`，再启动服务。

## 二、让家人在微信里打开

### 场景 A：人在同一个家里、连同一个 WiFi

1. 查看电脑局域网 IP（PowerShell 运行）：

   ```powershell
   ipconfig
   ```

   找「无线局域网适配器 WLAN」或「以太网」里的 `IPv4 地址`，形如 `192.168.x.x`。

2. 手机连同一个 WiFi，把 `http://192.168.x.x:3000` 发到家庭微信群，点开即可。
3. 注意：电脑要一直开着、服务不能关；电脑休眠后链接会失效。

### 场景 B：家人在外地，需要远程访问（推荐）

家里电脑没有公网 IP，需要用「内网穿透」工具把本地 3000 端口暴露成一个公网链接，工具会给出 `https://xxx` 地址，把这个地址发到微信群，家人微信点开就能用。常见工具：

- **Cloudflare Tunnel**（免费，稳定）：安装后运行 `cloudflared tunnel --url http://localhost:3000`，会输出一个公网 https 地址。
- **cpolar / 花生壳 / ngrok**：按各自文档把本地 3000 端口映射出去即可。

> 穿透工具给出的临时域名每次重启可能变化；固定域名需要工具账号付费配置。

### 场景 C：长期挂着、不依赖家里电脑

服务已适配平台端口：读取环境变量 `PORT`（默认 3000），健康检查接口 `GET /api/health`，启动命令 `node server.js`。下面两条路径任选其一。

#### 路径一：国内轻量云服务器（推荐，稳定、微信打开快）

适合长期给家人用。不用域名也能访问：直接用 `http://服务器公网IP:3000` 发到微信；国内服务器绑域名走 80/443 端口才需要备案，IP+端口不涉及备案。

1. **买服务器**：腾讯云 / 阿里云 / 华为云的「轻量应用服务器」，新人价通常很低；系统选 Ubuntu 22.04 LTS；地域选离家人近的。
2. **放通端口**：在服务器控制台的防火墙/安全组里放行 TCP `3000` 端口。
3. **装 Node**（SSH 登录后执行，以 Ubuntu 为例）：

   ```bash
   curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
   sudo apt-get install -y nodejs
   ```

4. **上传代码**：把整个 `family-order-app` 目录传到服务器（可用控制台的文件上传，或本地 `scp -r family-order-app 用户名@服务器IP:~/`）。
5. **常驻运行**（用 pm2 防止关掉 SSH 后服务停止）：

   ```bash
   cd family-order-app
   sudo npm i -g pm2
   ADMIN_PIN=你的口令 pm2 start server.js --name order-app
   pm2 save
   pm2 startup      # 按提示再执行一遍输出的命令，开机自启
   ```

6. **访问**：浏览器/微信打开 `http://服务器公网IP:3000`，能看到点菜页即成功，把这个链接发到家庭群。
7. **可选加固**：之后有域名了，再用 Nginx 反代到域名并配 HTTPS；需要时再处理备案。

> 数据保存在服务器磁盘的 `data/` 目录，不会像免费平台那样被清空；定期备份这两个文件即可。

#### 路径二：免费托管平台（零成本，先试用）

如 Render / Railway / Fly.io。优点是不用自己买服务器；缺点是免费版会休眠（冷启动几十秒）、国外节点国内访问偏慢、磁盘是临时的，服务重启后菜单和订单可能被清空。

1. 把代码推到一个 GitHub 仓库（包含 `server.js`、`package.json`、`public/`）。
2. 在平台新建 Web Service，关联该仓库：
   - Build 命令：留空或 `npm install`（本项目无依赖）；
   - Start 命令：`node server.js`；
   - 端口：平台自动注入 `PORT` 环境变量，代码已读取，不用手动填。
3. 环境变量里加 `ADMIN_PIN=你的口令`。
4. 部署完成后用平台给的公网 `https` 链接发微信群。

> 注意：免费平台磁盘临时，菜单要能接受重新录入；订单重要的话，后续再把数据改接到数据库。

## 三、日常使用说明

- **家人**：打开链接 → 点菜 → 点底部「去提交」→ 填称呼 → 提交订单。
- **主人**：打开链接 → 底部「订单」→ 输入口令 → 查看新订单，做完点「完成」；「管理」里可以加减菜品、改价格。
- 订单数据保存在服务端 `data/orders.json`，菜单保存在 `data/menu.json`，备份时拷贝这两个文件即可。
